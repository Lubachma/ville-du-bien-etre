# Étape 2 — Contenu : bâtiments, merveilles, succès et ensembles : plan d'implémentation

> **Pour les agents :** sous-compétence REQUISE : superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans, tâche par tâche. Les étapes utilisent des cases à cocher (`- [ ]`).

**But :** une ville de 50 éléments, dont 3 merveilles construites en 4 étapes, avec 33 succès, 12 ensembles de voisinage, un carnet, une boutique rangée et une pose plus vivante. Une troisième langue ne demande plus que son dictionnaire.

- **Règles pures** :
  - prix, déblocages et merveilles dans `src/20-rules.js` ;

  - succès dans le nouveau `src/23-achievements.js`.
- **Dessins** dans trois nouveaux fichiers qui complètent `DRAW` : `31` (bâtiments), `32` (décors), `33` (merveilles).
- **Interface** : carnet, célébrations et rattrapage dans le nouveau `src/52-carnet.js`. Le reste vient en petites retouches des fichiers existants.

**Pile technique :** JavaScript sans framework (IIFE assemblée par `scripts/build.mjs`), canevas 2D, Web Audio, `node:test` dans une machine virtuelle Node, Playwright.

**Spécification :** `docs/superpowers/specs/2026-10-18-contenu-design.md` (approuvée). La lire avant chaque tâche : ses règles ne sont pas toutes répétées ici.

## Points de vigilance

Cinq situations que la spécification implique sans les nommer. Chacune a son test dans la tâche indiquée.

1. **Ville existante très remplie au premier lancement** : 1 000 jours actifs, 150 sessions d'historique, un ensemble déjà formé. Un seul message, et un rattrapage de moins de 1,5 s (Task 11).
2. **Une pièce d'ensemble démolie, ou déplacée hors du carré** : le pavage disparaît et la découverte reste (Task 8).
3. **Deux onglets : l'un déplace une merveille, l'autre construit l'étape suivante.** La fusion garde la nouvelle case et l'étape la plus haute, sans remboursement (Task 3).
4. **Pièces exactement égales au prix d'une étape** : le bouton est actif ; avec une pièce de moins, il est inactif (Task 6).
5. **Décor offert posé gratuitement, puis démoli** : le suivant est de nouveau gratuit. Un exemplaire gratuit ne compte pas pour « Première pierre » (Tasks 2 et 9).

| `dayMinutes` | un jour avec `stats.days[jour] ≥ n` |
| `dayCats` | un jour avec au moins `n` domaines à plus de 0 min dans `stats.dailyCats` |
| `activeDays` | au moins `n` jours avec `stats.days[jour] > 0` |
| `streak` | un jour actif `d` avec `streakDetail(d).days ≥ n`, en parcourant les jours dans l'ordre et en s'arrêtant au premier trouvé |
| `totalMinutes` | somme de `stats.byCat ≥ n` |
| `tiles` · `citySize` · `nature` | `city.tiles.length ≥ n` · `city.size ≥ n` · cases dont l'élément est dans `NATURE_ITEMS` `≥ n` |

| `sets` · `wonders` | `Object.keys(sets).length ≥ n` · merveilles posées à l'étape 4 `≥ n` |

*Écart assumé avec la spécification.* Elle pensait que les succès du tirage et des routines ne se retrouvent pas dans les données conservées. Or l'historique garde l'origine de chaque session (`source`), et l'état garde la dernière routine (`routineRun`). Ces deux succès se rattrapent donc aussi pour les villes existantes, ce qui est plus généreux et reste fidèle à la règle « la vraie date quand elle se déduit des données ». Limite : seule la dernière routine est gardée. Une routine finie plus tôt, suivie d'une routine en pause, n'est reconnue qu'à la prochaine routine terminée.

function memoryStorage() {
  const data = new Map();
  return { getItem: k => (data.has(k) ? data.get(k) : null), setItem: (k, v) => data.set(k, String(v)), removeItem: k => data.delete(k), clear: () => data.clear() };

function loadApp(files, { now = '2026-10-18T12:00:00Z', expose = [], globals = {} } = {}) {
  const wall = Date.parse(now);
  class Clock extends Date { constructor(...a) { super(...(a.length ? a : [wall])); } static now() { return wall; } }
  const context = vm.createContext({ console, Date: Clock, Intl, Math, JSON, setTimeout, clearTimeout, TextEncoder, TextDecoder,
    window: {}, document: { documentElement: {} }, navigator: { languages: ['fr-CH'] }, localStorage: memoryStorage(), ...globals });

const test = require('node:test');
const assert = require('node:assert/strict');
const { loadApp } = require('./helpers/app.cjs');

// Joueur de référence : même durée chaque jour, cinq domaines à parts égales, +45 % de bonus.
// Il achète un exemplaire de chaque élément (hors décors offerts) et chaque étape de merveille dès qu'il le peut,
// le moins cher d'abord, et agrandit sa ville quand il reste deux cases libres ou moins.
function simulate(minutesPerDay) {
  const a = loadApp(['00-core.js', '05-i18n.js', '06-lang-fr.js', '07-lang-en.js', '10-state.js', '20-rules.js'], { expose: ['ITEMS', 'EXPAND_PRICE', 'CAT_ORDER', 'lockInfo'] });
  const { ITEMS } = a, keys = Object.keys(ITEMS).filter(k => !ITEMS[k].reward);
  const owned = new Set(), stage = {};
  let coins = 5e6, size = 7, placed = 6, allUnlocked = 0;
  for (let day = 1; day <= 1500; day++) {
    for (const c of a.CAT_ORDER) a.state.stats.byCat[c] += minutesPerDay / 5;
    const total = minutesPerDay * day;
    coins += minutesPerDay * 1e6 * 1.45;
    if (!allUnlocked && keys.every(k => !a.lockInfo(k) && (!ITEMS[k].wonder || ITEMS[k].wonder.every(([need]) => total >= need)))) allUnlocked = day;
    for (;;) {
      const room = size * size - placed, options = [];
      for (const k of keys) {
        const w = ITEMS[k].wonder;
        if (w) { const s = stage[k] || 0; if (w[s] && total >= w[s][0] && (s || room > 0)) options.push({ k, price: w[s][1] }); }
        else if (!owned.has(k) && room > 0 && !a.lockInfo(k)) options.push({ k, price: ITEMS[k].price });
      }
      if (room <= 2 && size < 11) options.push({ expand: true, price: a.EXPAND_PRICE[size + 2] });
      const choice = options.sort((x, y) => x.price - y.price).find(o => o.price <= coins);
      if (!choice) break;
      coins -= choice.price;
      if (choice.expand) size += 2;
      else if (ITEMS[choice.k].wonder) { if (!stage[choice.k]) placed++; stage[choice.k] = (stage[choice.k] || 0) + 1; }
      else { owned.add(choice.k); placed++; }
    }
    if (keys.every(k => (ITEMS[k].wonder ? stage[k] === ITEMS[k].wonder.length : owned.has(k)))) return { allUnlocked, allBuilt: day };
  }
  return { allUnlocked, allBuilt: Infinity };
}

test('rythme : environ un an à 30 min par jour', () => {

  assert.ok(r.allUnlocked >= 240 && r.allUnlocked <= 300, JSON.stringify(r));
  assert.ok(r.allBuilt >= 340 && r.allBuilt <= 410, JSON.stringify(r));
});

test('rythme : plus on pratique, plus on avance vite', () => {
  const [slow, ref, fast] = [20, 30, 45].map(simulate);
  assert.ok(slow.allBuilt > ref.allBuilt && ref.allBuilt > fast.allBuilt, JSON.stringify({ slow, ref, fast }));
});

| kind | Date |
|---|---|
| `sessions` (n = 1) | premier jour de `stats.days` |
| `catMinutes`, `totalMinutes` | jour où le cumul de `dailyCats` (par domaine) ou de `days` atteint le seuil |
| `activeDays` | n-ième jour actif |
| `dayMinutes`, `dayCats`, `weekCats` | premier jour (ou jour du 5e domaine) qui remplit la condition |
| `streak` | premier jour où la série atteint `n` |
| `endHour`, `sessionMin`, `draw` | entrée d'historique la plus ancienne qui remplit la condition (`at`) |
| `routine` | `routineRun.finishedAt` |
| `bought` | le plus ancien `at` des cases payées |
| `tiles`, `nature` | construction de la n-ième case encore posée (ajouté après la revue finale) |
| autres | 0 (donc `now`) |

Un jour `AAAA-MM-JJ` donne `keyToUTC(jour)`.
